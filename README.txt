## Software Engineering Diagram Artifact Learning Studio

An interactive learning studio for exploring software engineering diagrams
and modelling artifacts. Open the HTML file in a browser to use it locally.

The example image is stored in the repository and loaded with a relative path,
so it also works when the project is published as a static site.

## GitHub Pages

Live site: https://zechariah-guo.github.io/Modelling-Tools/
